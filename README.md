 **Doce Conexão | Joy Silva**

Site desenvolvido para a confeitaria **Joy Silva – Bolos e Doces Finos**, com o objetivo de apresentar seus produtos, facilitar a navegação pelo catálogo e direcionar os clientes para solicitações de orçamento.

Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

Funcionalidades

- Catálogo de bolos, doces, kits festa e topos de bolo.
- Páginas individuais para as categorias de produtos.
- Layout responsivo.
- Integração com WhatsApp e redes sociais.
- API em PHP para consulta de produtos.
- Integração entre JavaScript e banco de dados MySQL.

Banco de dados e API

O projeto utiliza uma API desenvolvida em PHP para consultar os produtos cadastrados no MySQL.

As informações são retornadas em formato JSON e utilizadas pelo JavaScript para atualizar os cartões do catálogo.

A integração funciona localmente com Apache e MySQL pelo XAMPP.
